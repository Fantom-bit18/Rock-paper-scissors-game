Консольная игра 'Камень, ножницы, бумага' против компьютера. Пользователь вводит количество раундов, которые хочет сыграть, а далее выбирает один из вариантов (К - камень, Н - ножницы, Б - бумага). Компьютер также делает свой ход, и определяется результат раунда. Далее процесс повторяется. После того, как все раунды будут сыграны, выводится итоговый счет и результат всей игры в целом.
